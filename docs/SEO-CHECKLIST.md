# SEO-чек-лист Arendora (Google + Яндекс)

Что уже сделано в коде — см. последний блок. Здесь — шаги, которые выполняются
вручную, в кабинетах поисковиков, и решения, которых нет в репозитории.

## Один раз: регистрации

1. **Google Search Console** (https://search.google.com/search-console)
   - Добавить домен, подтвердить (DNS-запись, если будет свой домен).
   - Отправить `sitemap.xml`.
   - Через 2–4 недели смотреть: «Покрытие», «Эффективность», новый отчёт
     «AI features» (показы в AI-ответах Google).
2. **Яндекс Вебмастер** (https://webmaster.yandex.ru)
   - Добавить сайт, подтвердить (meta-тег или DNS).
   - Отправить `sitemap.xml`, проверить `robots.txt` встроенным анализатором.
   - **Региональность → «Россия»** (федеральный онлайн-сервис; город даёт
     преимущество только по гео-запросам).
   - «Проверка загрузки страницы» с юзер-агентом Яндекс-бота — убедиться,
     что робот видит контент страниц (SPA!).
3. **Яндекс Бизнес** (https://business.yandex.ru)
   - Заполнить карточку организации ≥90%, подтвердить владение, указать сайт.
   - Даже для чисто онлайн-сервиса: карточка обогащает брендовый сниппет,
     подтягивает регион и отзывы (с апдейта Y1 отзывы с Карт влияют и на
     обычный поиск).

## Один раз: Яндекс.Метрика

- Получить ID счётчика в Метрике → при сборке задать
  `VITE_YANDEX_METRICA_ID=12345678`. Скрипт в `index.html` подключится сам.
- Настроить цели: регистрация, загрузка демо-данных, просмотр тарифов.
  Достижение целей — поведенческий фактор, у Яндекса он весит больше, чем
  у Google.
- Webvisor включён в скрипте по умолчанию.

## Один раз: коммерческие факторы (Яндекс проверяет их на товарных запросах)

- **Реквизиты.** В «Оферте» (раздел 9 «Реквизиты») стоят плейсхолдеры
  `[ФИО исполнителя — ИП или ООО], ИНН [ИНН]`. После оформления ИП/ООО
  вписать реальные реквизиты туда и на лендинг в футер (ИНН/ОГРН/юрстатус).
  Без реквизитов коммерческие запросы ранжируются плохо.
- **Телефон.** Сейчас на сайте только email. Городской номер или 8-800
  в футере лендинга усилит и доверие, и коммерческие факторы.
- **Цены** уже есть (блок тарифов), **оферта** есть, HTTPS будет на деплое.

## Контент-план (важнее ссылок)

Приоритет — «низ воронки» (конвертируют лучше всего):
- «альтернативы <конкурент>», «<конкурент> vs Arendora»;
- «программа для учёта аренды / управления квартирами» (статья есть);
- «учёт аренды в Excel» (статья есть);
- «как сдать квартиру» (статья есть).

Правила, подтверждённые исследованием 10.2026:
- 1 тематический кластер = 1 опорная статья + 5–10 связанных, перелинковка
  между собой и на лендинг (в статьях уже проставлены внутренние ссылки).
- Информационные статьи потеряли 30–40% кликов из-за AI Overviews —
  писать узко и по первому опыту (то, что AI не суммирует): собственные
  цифры, шаблоны договоров/оперси, расчёты.
- Нейротекст без экспертной правки ловится «Баден-Баденом» Яндекса.
  Схема: ИИ-черновик → человеческая экспертиза, цифры, продукт-специфика.
- Каждую новую статью добавить в `public/sitemap.xml` (там есть комментарий).

## Техдолг (когда будет свой домен/VPS)

- **Пререндер ключевых страниц.** Google рендерит JS, но ставит в очередь;
  Яндекс рендерит медленнее, AI-боты часто не рендерят вовсе. Самое сильное
  техническое улучшение — prerender/SSG лендинга, блога и правовых страниц
  (`vite-plugin-prerender` или Vike). Не делать «на коленке» — только после
  стабильного домена и CI.
- `hreflang` НЕ нужен: RU/EN переключаются на клиенте на тех же URL.
  Заводить только если появятся отдельные en-адреса.
- Метрика кор-веб-виталов Google: LCP ≤ 2.5с, INP ≤ 200мс, CLS ≤ 0.1
  (замер — отчёт CWV в Search Console, полевые данные).
- Не покупать «накрутку поведенческих» — у Яндекса за это бан на 8–12 мес.

## Что уже сделано в коде (10.2026)

- Убраны мёртвые элементы: `meta keywords`, JSON-LD FAQPage/HowTo
  (rich-результаты Google отключены), SearchAction.
- JSON-LD на лендинге: Organization (+контакты, logo), WebSite,
  SoftwareApplication (+Offer) — валидно для обоих поисковиков.
- На статьях блога: Article + BreadcrumbList (Яндекс поддерживает хлебные
  крошки, игнорирует Article безвредно).
- `usePageMeta`: на каждой публичной странице свой title/description +
  self-canonical + og:title/description/url (UTM-копии больше не дубли).
- `robots.txt`: Clean-param для Яндекса; `sitemap.xml`: только loc+lastmod,
  статьи блога включены.
- Яндекс.Метрика подключается через `VITE_YANDEX_METRICA_ID` (пока пусто —
  счётчика нет, ноль запросов).
- Блог отфильтрован: только статьи из `content/blog/`; соц-посты и рассылки
  из `content/` в индекс не попадают.
- Тема на лендинге: переключатель в шапке + предзагрузка темы без «мигания».

## Проверка после деплоя

- https://search.google.com/test/rich-results — лендинг и статья блога.
- Валидатор Яндекса в Вебмастере («Валидатор микроразметки»).
- `curl https://<домен>/robots.txt` — токены заменились.
