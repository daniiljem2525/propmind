# PropMind

Современная облачная SaaS-платформа для управления портфелем недвижимости (от 100+ объектов): объекты, арендаторы, платежи, заявки на обслуживание, документы и аналитика — в едином интерфейсе. Двуязычная (RU/EN), светлая и тёмная темы.

## Маркетинг и продажи

- **Публичный лендинг на `/`**: hero с мини-макетом дашборда, 6 возможностей, «как это работает» за 3 шага, тарифы, FAQ, финальный CTA и футер. Залогиненные пользователи автоматически попадают в приложение.
- **Воронка:** лендинг → регистрация (без карты, Free навсегда) → онбординг-чеклист на дашборде (объект → арендатор → платежи) → демо-данные одним кликом.
- **Приложение живёт на `/app/*`** — чистое разделение витрины и продукта.
- В тарифах (лендинг и настройки): гарантии «15 минут / без карты / отмена в любой момент» и контакт для enterprise.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Быстрый старт за 15 минут

1. Откройте приложение → **Зарегистрироваться** (email + пароль, код подтверждения показывается на экране — демо-режим без почтового сервера).
2. На дашборде нажмите **«Загрузить демо-данные»** — 8 объектов, 5 арендаторов, полгода истории платежей, заявки, документы и уведомления в один клик.
3. Или начните с нуля: **Объекты → Добавить** (нужны только название, адрес и сумма аренды), затем **Арендаторы → Добавить** с привязкой к объекту.

## Ключевая автоматизация

- **Автосвязывание арендатора**: при создании арендатора с объектом платформа сама проставляет арендатора на объекте, меняет статус на «Сдаётся» и создаёт первый платёж на сумму аренды.
- **График на 12 месяцев**: кнопка у арендатора создаёт 12 ежемесячных платежей (с защитой от дублей по периоду).
- **Автозаполнение форм**: выбор арендатора в платеже подставляет объект и сумму; выбор объекта в заявке подставляет арендатора.
- **Дефолты**: валюта RUB, договор «сегодня → +1 год», минимум обязательных полей.

## Стек

- **Frontend:** React 18 + Vite, Tailwind CSS, lucide-react, recharts, framer-motion, react-router-dom
- **Данные:** локальное хранилище (localStorage) с realtime-синхронизацией между вкладками (BroadcastChannel). Слой изолирован в `src/lib/api/` — при необходимости заменяется на внешний бэкенд без изменения UI.

## Структура

```
src/
  lib/
    api/        # хранилище, сущности (Property, Tenant, Payment, ...), auth+OTP, файлы
    services.js # бизнес-логика: автосвязывание, график платежей, уведомления
    i18n/       # RU/EN словари + LangContext (useLang → t(key))
    config/     # статусы, типы, тарифы (label_ru/label_en)
    demo.js     # генератор демо-данных
  components/   # UI-кит (button, card, dialog, toast...), лейаут (Sidebar, Header), общие
  pages/        # Landing (публичный), Dashboard, Properties, Tenants, Payments,
                # Maintenance, Documents, Analytics, Settings, Notifications + auth/
```

## Автоматизация

- **Автопросрочка:** при входе в приложение `pending`-платежи с прошедшей датой становятся `overdue`, владельцу создаётся уведомление.
- **Автосвязывание арендатора:** статус объекта → «Сдаётся», первый платёж создаётся сам.
- **График на 12 месяцев:** одной кнопкой, с защитой от дублей по периоду.
- **Продление договора:** кнопка «Продлить на год» у истекающих договоров — новая дата + график платежей.
- **Быстрое создание:** кнопка «+» в шапке открывает диалог создания на нужной странице (`?new=1`).

## Аутентификация и роли

- Регистрация email+пароль с OTP-подтверждением, вход, восстановление пароля по токену.
- Роли: `admin` (управление пользователями, приглашения) и `user`.
- Данные каждого пользователя изолированы (owner_id на всех записях).

## Примечания

- Демо-режим хранит всё в браузере: Google OAuth и Stripe-онлайн-оплата — заглушки (платёж помечается оплаченным), коды OTP показываются на экране.
- Файлы хранятся как data-URL (лимит 1,5 МБ) — при подключении внешнего хранилища замените `src/lib/api/files.js`.
