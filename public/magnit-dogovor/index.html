Текст шаблона

ДОГОВОР НАЙМА ЖИЛОГО ПОМЕЩЕНИЯ

г. __________ «___» __________ 20___ г.

Наймодатель: ФИО, паспорт, адрес регистрации — ____

Наниматель: ФИО, паспорт, адрес регистрации — ____

Проживающие совместно: ____

1. Предмет. Наймодатель передаёт во временное пользование квартиру по адресу ____ (кадастровый № ____), пригодную для проживания, вместе с имуществом по описи (Приложение № 1).

2. Срок найма. С «___» ____ 20__ по «___» ____ 20__ г. Стороны уведомляют друг друга о непродлении за ____ дней до окончания срока.

3. Плата за наём. ____ ₽ в месяц. Оплата — до 20:00 ____ числа текущего месяца, реквизиты — в Приложении № 2. Первый платёж включает залог: ____ ₽. Почему важно: точное время и реквизиты снимают спор «я заплатил/не заплатил».

4. Порядок расчётов. Плата за наём и коммунальные услуги взыскивается раздельно: наймодатель оплачивает ____; наниматель оплачивает ____ (счётчики фиксируются в акте приёма-передачи).

5. Залог (обеспечительный платёж). ____ ₽. Покрывает: ущерб имуществу, задолженность по плате/коммуналке. Не засчитывается как оплата последнего месяца. Возврат — в течение ____ дней после выезда и подписания акта, при отсутствии претензий. Типичная ошибка: устное «залог = последний месяц».

6. Права и обязанности нанимателя. Использовать квартиру только для проживания, не сдавать в субаренду без письменного согласия, не перепланировать, соблюдать тишину по правилам региона.

7. Права и обязанности наймодателя. Передать квартиру и имущество в состоянии, пригодном для проживания, не менять замки и не посещать квартиру без согласия нанимателя (кроме аварий), производить капитальный ремонт.

8. Досрочное расторжение. Наниматель — с уведомлением за ____ дней; при выезде до конца срока плата за ____ дней ____ (вариант: удерживается из залога / не удерживается). Наймодатель — с уведомлением за ____ дней. Одностороннее изменение условий не допускается.

9. Ответственность. За просрочку платы — пеня ____% за каждый день просрочки (вариант: фиксированный штраф за каждый полный день просрочки — по договорённости сторон). За порчу имущества — возмещение по описи с учётом износа.

10. Акт приёма-передачи. Квартира и имущество передаются по Приложению № 1 (опись + фото + показания счётчиков). Возврат — по акту. Отсутствие претензий в акте = отсутствие оснований для удержаний из залога.

11. Изменение условий. Размер платы за наём может изменяться по соглашению сторон не чаще 1 раза в год и не ранее чем через ____ месяцев проживания. Уведомление — письменно (месседжер/почта, указанная в Приложении № 2).

12. Прочее. Споры — переговоры, при недостижении согласия — суд по месту нахождения квартиры. Договор составлен в 2 экземплярах. Неотъемлемые приложения: № 1 опись имущества, № 2 реквизиты и контакты, № 3 акт приёма-передачи.
