# Виджет Arendora на iPhone

Виджет на экран «Домой» показывает **ближайший неоплаченный платёж**:
сумму крупно, жильца и дату (просрочка — красным), внизу — задолженность
и сколько платежей впереди. Обновляется iOS'ом примерно раз в 5–15 минут.

Работает через бесплатное приложение **Scriptable** — нативная разработка
не нужна, виджет — это JS-скрипт из этого файла.

## Установка (5 минут)

1. **App Store → установите «Scriptable»** (бесплатно).
2. Скопируйте содержимое [`ArendoraWidget.js`](./ArendoraWidget.js).
3. Откройте Scriptable → «+» (новый скрипт) → вставьте → назовите `ArendoraWidget`.
4. В самом верху скрипта заполните `CONFIG`:
   - `SUPABASE_URL` — уже вписан;
   - `SUPABASE_ANON_KEY` — **публичный anon-ключ** проекта (Supabase →
     Settings → API → Legacy anon/public; **не** service_role!);
   - `EMAIL` и `PASSWORD` — ваша учётка Arendora.
5. На экране «Домой» → долгое нажатие → «+» → найдите **Scriptable** →
   добавьте виджет → в настройках виджета выберите скрипт `ArendoraWidget`
   → размер Medium (2×2).
6. Готово: крупная сумма ближайшего платежа, жилец и дата, задолженность.

## Как это устроено

- Виджет логинится в Supabase под вашей учёткой (anon-ключ + email/пароль).
  Данные фильтруются RLS — видны только **ваши** платежи; сервисный ключ
  на телефоне не используется.
- Токен кэшируется на 50 минут, чтобы не логиниться при каждом обновлении.
- Если сети нет — виджет покажет «Нет связи» и повторит через 10 минут.

## Ограничения

- Частоту обновления задаёт iOS (обычно раз в 5–15 минут, мгновенно — нельзя).
- Партиальные платежи показываются полной суммой (остаток в базе не хранится).
- Клик по виджету открывает Scriptable; переход в Arendora можно добавить
  позже через `Safari.openInApp`.

## Хотите другой виджет?

Скрипт легко расширить: отклики с Профи (`profi_offers`), заявки
(`maintenance_requests`), заказы служб (`automation_orders`) — тот же
паттерн: REST-запрос + строки на виджете. Попросите — добавлю.
